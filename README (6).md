# 기사 프로젝트 노트

기사 프로젝트 진행 상황을 한 페이지에 적어 두는 간단한 노트입니다. HTML 파일 하나로 되어 있어 설치 없이 브라우저에서 바로 열 수 있습니다.

## 기능

- **프로젝트 한 줄** : 프로젝트를 한 줄로 요약해 적는 칸
- **주제** : 대주제만 적는 칸
- **할 일** : 체크리스트 5개
- **날짜별 기록** : 세로선 위에 날짜가 점으로 찍히는 타임라인 형태
  - 11/18부터 시작하고, 날짜마다 오늘 한 줄을 적습니다.
  - 내용을 적으면 점이 채워지고, 오늘 날짜는 남색으로 강조됩니다.
  - `+ 다음 날 추가` 버튼으로 다음 날짜 칸을 늘립니다.

## 사용 방법

1. `기사_프로젝트_노트.html` 파일을 내려받습니다.
2. 브라우저(Chrome, Safari 등)에서 파일을 엽니다.
3. 칸에 내용을 적으면 자동으로 저장됩니다.

휴대폰 화면에서도 보이도록 화면 폭에 맞춰 표시됩니다.

## 저장 방식

입력한 내용은 사용 중인 기기의 브라우저(`localStorage`)에만 저장됩니다. 서버로 전송되지 않으며, 다른 기기나 다른 브라우저에서는 보이지 않습니다. 브라우저 데이터를 지우면 기록도 함께 지워집니다.

## 색 바꾸기

파일 맨 위 `<style>` 안의 `:root`에 있는 색 값 5개(`--bg`, `--card`, `--ink`, `--accent`, `--line`)만 바꾸면 전체 색이 바뀝니다.

## 개인정보

전화번호, 주소 같은 개인정보를 입력받는 칸은 없습니다.

## GitHub Pages로 공개하기 (선택)

1. 파일 이름을 `index.html`로 바꿔 저장소에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포할 브랜치를 선택합니다.
3. 안내된 주소로 접속하면 어디서든 열 수 있습니다. (기록은 접속한 기기에만 저장됩니다.)
